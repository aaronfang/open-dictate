# Open Dictate 产品路线图

开源的系统级语音输入工具：全局热键 → 录音 → 语音识别 → 任意 App 光标处上屏，并提供 **本地优先、云端可选** 的文本润色。

本文档描述完整产品愿景、当前进度与分阶段目标。实现细节见 [providers.md](providers.md)、[privacy.md](privacy.md)、[building.md](building.md)。

## 产品愿景

- **系统级听写**：不绑定某一编辑器，在任意输入框可用
- **本地优先**：默认音频与识别不出网；云端能力需用户显式开启
- **可插拔**：STT（识别）与 PostProcessor（润色）可替换
- **可复用内核**：Rust Core + UniFFI，供 macOS / 未来其他平台共用
- **个人化**：个人词典、按 App 语气/格式画像

## 分阶段路线图

### P0 — 听写体验打磨（近期 / 基本完成）

目标：安静环境下「按住说话 → 文字上屏」稳定可用。

- [x] 全局热键录音与松键识别
- [x] SenseVoice / whisper.cpp 引擎切换
- [x] 文本注入（记住目标 App、Cmd+V）
- [x] SenseVoice 冷启动预热与就绪提示
- [x] 首尾静音裁剪（缓解 `<|nospeech|>` 空结果）
- [x] 设置页分组与文档状态对齐（SenseVoice / 本地 LLM / 可配热键已落地）
- [ ] 正式 `.app` 打包与签名分发
- [ ] 点按切换听写模式（现为按住说话）

### P1 — 嘈杂环境与识别质量

目标：车站、人群等场景下可用率明显提升（无法等同安静环境）。

- [ ] 录音前端：系统 Voice Processing（噪声抑制 / AGC）可开关
- [ ] 轻量预处理：高通滤波、强制语言（如中文）选项
- [ ] 更稳的 VAD（替代纯 RMS 静音裁剪）
- [ ] 可选专用降噪（如 RNNoise）再送入 STT
- [ ] 嘈杂场景策略（可选：加强降噪或切换引擎；默认仍优先 SenseVoice）

### P2 — 文本智能

目标：识别结果更像「写出来的字」，并支持个人习惯。

- [x] 规则后处理默认开启（去口癖、空白归一化）— Swift MVP；P3 收敛 `core/core-llm` rules
- [x] 个人词典管理 UI + 本地 SQLite（schema 对齐 `core-store` `dictionary`；P3 收敛 Core）
- [x] 按 App 画像（语气 / 格式）UI + 本地 `app_profiles`（Swift MVP；P3 收敛 Core）
- [x] 可选云端 LLM 润色（DeepSeek / OpenAI 兼容）；UI 明示出网为「文本」— Swift MVP
- [x] 可选本地 LLM 润色（自动下载 Qwen2.5-3B GGUF + llama-cli，无需 Ollama）

### P3 — 架构收敛

目标：外壳与内核统一，避免 Swift / Rust 双轨逻辑漂移。

- [ ] macOS 接入 UniFFI 绑定与动态库（见 `scripts/build_macos_core.sh`）
- [ ] 听写主路径走 Core `Pipeline`（STT → 词典 → 润色）
- [ ] 设置、隐私展示与 Core 配置一致
- [ ] `core-audio`：VAD / 重采样 / 环形缓冲（替代部分外壳临时逻辑）

### P4 — 云端与扩展能力

目标：在用户知情前提下提供云端能力与可选历史。

- [ ] 火山 ASR 完整接入（现有 OpenAI 兼容事件流；可选 v3 二进制 transport）
- [ ] 云端 Provider 开关、API Key、当前出网类型（音频 / 文本）明示
- [ ] 可选「历史记录」：默关、仅本地、可一键清除（见 [privacy.md](privacy.md)）

### P5 — 跨平台（远期）

目标：同一 Core，多端外壳。

- [ ] Windows 外壳（热键 + 注入）
- [ ] Android / 其他（Kotlin 等 UniFFI 消费方）
- [ ] 统一配置与词典同步策略（若需要，仍默认本地）

## Typeless 特性对照

对照对象：[Typeless](https://www.typeless.com/)（官方站点 / [User Guide](https://typeless.cc/en/user-guide.html) / [Key Features](https://www.typeless.com/help/quickstart/key-features) / Pricing，2026）。Typeless 以**云端 AI 听写**为主；Open Dictate 以**本地优先**为产品原则，下列「已实现」指能力对等或可替代，不要求同一实现路径。

### Typeless 完整特性清单

| # | 特性 | Typeless 说明 |
|---|------|----------------|
| T1 | 全局听写 | 任意 App 输入框；快捷键开始/结束；上屏到光标处 |
| T2 | AI 去口癖 | 自动去掉 um / uh / you know 等 |
| T3 | AI 去重复 | 去掉口头重复、赘余 |
| T4 | 改口识别 | 识别「说错再改」并只保留最终意图 |
| T5 | 意图理解 / 措辞优化 | 不只转写，按语义整理成更通顺的书面语 |
| T6 | 自动排版 | 口语列表、步骤、要点 → 结构化文本 |
| T7 | 按 App 语气 | 邮件正式、聊天随意等，随前台 App 适配 |
| T8 | 个人词典 | 手动添加专有名词；亦可自动学习词汇 |
| T9 | 写作风格学习 | 随使用逐渐贴近个人语气与习惯（含个性化进度） |
| T10 | 100+ 语言 | 自动语种检测；可中英混说 |
| T11 | Speak-and-Translate | 用母语说，输出目标语言；独立开关与快捷键 |
| T12 | Ask AI | 选中文本 + 语音指令：改写 / 摘要 / 解释 / 翻译 / 头脑风暴等 |
| T13 | Ask 只读文本 | 网页/文档只读选区也可摘要、解释、翻译 |
| T14 | Ask 联网助手 | 查天气、检索、打开页面并带上上下文（偏 Agent） |
| T15 | 可配置快捷键 | 听写 / Ask / Translate 均可自定义 |
| T16 | 点按切换听写 | 再按一次结束（非仅按住） |
| T17 | 语音校准 | 首次约 30 秒朗读，适配口音 |
| T18 | Whisper mode | Pricing 列出的 Pro 能力（低声/私密听写类） |
| T19 | 本机历史 | 听写历史存本机；可控制保留时长 |

| T22 | 移动端语音键盘 | iOS / Android 系统级键盘形态 |

| T24 | 配额与 Pro | 免费周字数上限、增强精度、高峰优先、团队管理等 |

### 与 Open Dictate 对照

| Typeless | Open Dictate | 差距说明 |
|----------|--------------|----------|
| T1 全局听写 | **已有** | 菜单栏 + 可配热键 + 剪贴板注入 |
| T2 去口癖 | **部分** | 规则后处理 + 可选 LLM；非云端实时「智能编辑」同级 |
| T3 去重复 | **部分** | 主要依赖 LLM；规则层较弱 |
| T4 改口识别 | **弱 / 缺** | 无专用改口模型；LLM 偶发能修，不稳定 |
| T5 措辞优化 | **部分** | 本地/DeepSeek 润色可做；默认关，质量依赖模型 |
| T6 自动排版 | **部分** | App 画像 format + LLM；无专用「列表/步骤」结构化管线 |
| T7 按 App 语气 | **已有** | `app_profiles` Bundle ID → tone/format |
| T8 个人词典 | **部分** | 手动 CRUD + 听写替换；**无**自动学习词典 |
| T9 风格学习 | **缺** | 无长期风格画像 / 个性化进度 |
| T10 多语言 | **部分** | SenseVoice/Whisper 有限语种；无「100+ 自动检测+混说」产品体验 |
| T11 边说边译 | **缺** | 无 Translate mode |
| T12–T14 Ask AI | **缺** | 无选区语音指令、只读摘要、联网 Agent |
| T15 可配快捷键 | **部分** | 听写热键可配；Ask / Translate 快捷键随对应能力未做 |
| T16 点按切换 | **缺** | 仅按住说话 |
| T17 语音校准 | **缺** | 无首次校准流程 |
| T18 Whisper mode | **缺** | 未做 |
| T19 本机历史 | **缺** | roadmap P4 远期 |
| T20 账号同步 | **非目标倾向** | 本地优先；若做应可选且默关 |
| T21–T22 跨平台 / 键盘 | **远期** | P5；移动键盘未规划为近期 |
| T23 隐私模型 | **路径不同** | 我们默认本地 STT；云端需显式开。Typeless 为云端处理 + 宣称零留存 |
| T24 配额 / Pro | **不适用** | 开源本地工具，无 SaaS 配额 |

### 主要未实现特性（按优先级建议）

相对 Typeless，当前 **缺口最大、且仍符合「本地优先听写」定位** 的能力：

1. **改口识别（T4）** — Typeless 核心卖点之一；规则/通用润色覆盖不足  
2. **Speak-and-Translate（T11）** — 独立产品能力，与听写并列  
3. **Ask AI / 选区语音编辑（T12–T13）** — 第二交互面；不含联网 Agent 也可先做本地改写  
4. **点按切换听写（T16）** — 听写热键已可配；缺再按一次结束  
5. **自动排版与更强 AI 编辑（T3/T5/T6）** — 向「说完即成稿」靠拢（可加强本地 LLM prompt / 专用规则）  
6. **词典自动学习 + 风格学习（T8 后半 / T9）** — 个人化深度  
7. **本机听写历史（T19）** — 隐私可控的回顾与复用  
8. **语音校准（T17）** — 口音适配（本地模型侧可选）  
9. **Ask / Translate 独立快捷键（T15 剩余）** — 随对应能力一并做

可刻意不做或远期再议（与开源本地定位冲突或过重）：

- 账号云同步、SaaS 配额、团队 Pro（T20/T24）  
- 联网 Ask Agent（T14）— 若做须显式出网与权限  
- 移动语音键盘 / 全平台对等（T21–T22）— 见 P5  
- 以云端 ASR 为默认路径（与 Typeless 同构）

## 非目标

- 不做默认遥测或匿名使用统计上传
- 不默认上传音频或转写到云端
- 不以「必须联网」为产品前提
- 不追求替代专业远场会议转写（嘈杂多人场景仅尽力提升）
- 不以 Typeless 式账号 SaaS / 云端默认识别为产品前提（对照见上节）
