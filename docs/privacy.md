# 隐私模型（Privacy Model）

本项目默认目标：**本地优先（local-first）**，不做遥测，不在云端留存音频数据。

## 数据流概览

### 本地默认路径

- **音频**：由 macOS 外壳（Swift）采集，默认在本地处理
- **识别**：本地 `whisper.cpp`（CLI）或本地 CoreML（SenseVoiceSmall 预留）
- **润色**：规则层默认启用（去口癖/空白规范化）；LLM 润色为可选
- **存储**：个人词典、按 App 画像、必要设置存入本地 SQLite（见 `core/core-store`）；听写历史为可选、默关

### 云端可选路径（用户显式启用）

当用户选择云端 provider 时，可能会有出网请求：

- **云端 ASR（火山引擎）**：音频内容会发往云端用于识别
- **云端 LLM（DeepSeek / 火山/兼容 OpenAI）**：仅发送文本（识别结果），用于润色/格式化

本项目不会自动启用云端 provider。启用云端后仍建议：

- 使用 **用户自带的 API Key**
- 在 UI 中明确展示 **当前 provider** 与 **出网数据类型（音频/文本）**

macOS 当前已实现：可选 **本地 Qwen2.5-3B**（自动下载，仅本机推理）与 **DeepSeek（云端）** 文本润色（默认关；设置页三选一；云端明示「出网类型：文本」）。本地模型首次下载会访问 Hugging Face / GitHub 拉取权重与运行时。
## 本地存储内容

SQLite 默认包含：

- `dictionary`：个人词典（短语替换；可含纠错自动学习写入的词条）
- `app_profiles`：按 App 的画像（tone + settings_json）
- `dictation_history`：可选听写历史（默关；仅文本，不存音频）

听写历史（设置 → 数据存储）：

- 默认关闭
- 仅本地 SQLite
- 可配置保留天数，并可单条删除 / 一键清除

纠错自动进词典（设置 → 词典）：

- 默认开启，可关
- 上屏后读取焦点控件文本，与刚粘贴内容比对；学到的短替换写入 `dictionary`
- 不出网；不上传音频
